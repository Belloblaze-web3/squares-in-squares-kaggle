# Squares in Squares — Kaggle Submission Generator

A reproducible, validation-first solver for the Kaggle **Squares in Squares** competition.

The project has three layers: a geometry core with SAT overlap checks; deterministic rectangular/grid layouts plus optional simulated annealing; and streaming submission generation with strict validation.

## Competition metric

For puzzle `n`, Kaggle recomputes the axis-aligned enclosing side length `L` and scores:

```text
score(n) = L / sqrt(n) - 1
```

The leaderboard score is the sum across puzzles. Lower is better. `L` is not submitted. The safe baseline chooses an integer rectangle with `columns * rows >= n` and minimizes `max(columns, rows)`, then places one axis-aligned unit square in each cell.

## Quick start

```bash
cd /home/ubuntu/squares_in_squares
python3 -m venv .venv && . .venv/bin/activate
pip install -e .
python -m squares_in_squares.generate_submission --output artifacts/submission.csv --max-n 1000
python -m squares_in_squares.validate_submission artifacts/submission.csv --max-n 1000
python -m squares_in_squares.benchmark --max-n 1000
```

The generator streams all 500,500 data rows and does not load the full CSV into memory.

## Targeted optimization

Use annealing only for selected small puzzles, then retain the deterministic fallback elsewhere:

```bash
python -m squares_in_squares.generate_submission \
  --output artifacts/submission_annealed.csv --max-n 1000 \
  --anneal-max-n 16 --anneal-steps 30000 --seed 7
```

Every emitted layout is validated before writing. The optimizer uses continuous center/angle perturbations, an enclosing-side objective, boundary penalties, and exact SAT-based overlap rejection. It is intentionally bounded and reproducible.

## Validation guarantees

The validator checks the exact header, parseability, unique `id`, complete `n` groups, `square_id = 0..n-1`, actual rotated vertices inside the enclosing box, and pairwise positive-area overlap. Edge or corner touching is allowed within tolerance, matching the competition description.

## Kaggle upload

The official Kaggle CLI supports browser login or API-token authentication. After installing it and accepting the competition rules on Kaggle:

```bash
pip install kaggle
kaggle auth login
kaggle competitions submit -c squares-in-squares \
  -f artifacts/submission.csv \
  -m "Validated rectangular baseline generated by squares_in_squares"
```

No credentials are stored in this project. Kaggle's official API documentation describes `kaggle auth login` and the `competitions submit` workflow: https://www.kaggle.com/docs/api
